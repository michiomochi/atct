# Goal 212 terminal distribution research

- `README.md:16-30` documents the supported install as `claude plugin marketplace add michiomochi/atct` followed by `claude plugin install atct@atct`. It says the plugin's wrappers first-download verified binaries into `~/.atct/bin/`; no repository installer or ordinary-terminal update command is present.
- `bin/atct` and `bin/atct-mcp` are Bash launchers that delegate to `bin/_resolve`. `_resolve` accepts only `atct`/`atct-mcp`, requires `HOME`, and supports Darwin/Linux on amd64/arm64.
- `bin/_resolve:4-30,86-144` pins version `0.60.0`, downloads `atct_${VERSION}_${OS}_${ARCH}.tar.gz` plus the same-release `checksums.txt`, verifies SHA-256, extracts one binary, caches it as `~/.atct/bin/<binary>-0.60.0`, and `exec`s it. It exports `ATCT_ATCT_BIN` so the cached `atct-mcp` can find the matching wrapper.
- Cache maintenance in `bin/_resolve:47-53` removes `.download.*` directories older than 60 minutes, removes non-current-version files older than 14 days, and touches a cache hit. `tests/cache_prune_test.bash` covers pruning/touching and cleanup failure; concurrent cold downloads are not covered.
- `cmd/atct-mcp/main.go:19-45` resolves the daemon launcher in this order: executable `ATCT_ATCT_BIN`, an adjacent `atct`, then bare `atct` through `PATH`. `internal/daemonctl/ensure.go:25-119` starts `atct daemon` detached, reuses a healthy PID-plus-socket, and applies the fixed `~/.atct` registry/lock/version checks.
- The current plugin path is HTTP: `.codex-plugin/plugin.json` points at `.mcp.json`, whose server is `type: "http"` at `http://127.0.0.1:8787/mcp`; it does not invoke `bin/atct-mcp`. `.claude-plugin/plugin.json` registers `hooks/claude-hooks.json`, while `hooks/session-start` invokes its adjacent `../bin/atct` and starts the daemon only when context exists. The current Codex manifest has no hooks.
- Ordinary-terminal commands shown in `README.md` (`atct project add`, `atct daemon start`, and monitor commands) assume an `atct` executable is already on `PATH` or invoked by an explicit path. The tree contains no shell-profile change, PATH installer, or Homebrew formula. The older `doc/specs/2026-08-15-atct-plugin-distribution.md:206-238` only measured plugin `bin/` visibility in Claude's Bash tool, not an ordinary terminal; `doc/specs/2026-08-24-mcp-over-http.md` records the later HTTP switch.
- Related coverage is declarative/fixture-based: `tests/wrapper_test.bash` checks the HTTP MCP contract, manifest/version pinning, download/checksum/stdout behavior, and adjacent hook resolution; `tests/release_test.bash` checks synchronized manifest bumps and `bin/_resolve`; `.goreleaser.yaml` produces both binaries and `checksums.txt`; `script/release.sh` is the maintainer release/publish flow and runs `claude plugin update atct@atct` after publication.
