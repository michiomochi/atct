# タスク詳細をモーダルからページにする

日付: 2026-08-20
ゴール: タスク詳細モーダルが縦に長くなると見切れてしまうのでタスク詳細ページにするなりにしてほしい

## 解く問題

**モーダルは自分の内容を切る。** 回答履歴が縦に伸びると、`dialog` の高さが画面を超えた
分がそのまま見えなくなる。人間の指摘はこれである。

そして**モーダルの中身はアプリのどこからも到達できなかった。** 前日の spec の訂正に
書いたとおり、`decision_history` が `task_id` を返しておらず、回答履歴の節が一度も
描画されていない。**見切れる前に、そもそも出ていなかった。**

## 決定

### ページにする。モーダルは残さない

`/tasks/{id}` を作り、`TaskDetailModal` は削除する。**両方残すと同じ画面を 2 箇所で
保守することになる。** モーダルを閉じる代わりにブラウザの戻るを使う。

副産物として**タスクが URL を持つ。** 人間が 1 件を指してエージェントに渡せる。
ゴール ID を属性に出さない判断（前日）と矛盾しない。あれは「属性の表に UUID を並べない」
であって、URL を持たせないという意味ではない。

### タスク 1 件を返す API を作る

ページは URL からタスク ID しか知らない。**ゴール経由では取れない。**

`GET /api/tasks/{id}` がタスク・所属ゴール・open な決定・適用済みの履歴を返す。

**最初の実装はゴールを全件列挙して線形探索していた。** ゴール 45 件で 46 クエリになる。
`GetTaskGoalID` で直接引く形に直した。**動くことと、動き方が妥当であることは別である。**

見つからないときはセンチネル（`ErrTaskNotFound`）を返す。**呼び出し側が
`strings.Contains(err.Error(), "task not found")` で判定する形にしない。**
文言を変えた瞬間に黙って壊れる。

### daemon のルーティングを一般化する

**ここが今回いちばん危なかった。** 埋め込み配信は `/goals/` だけを Astro の動的ルート
（`dist/goals/_/index.html`）に振っており、`/tasks/<id>` はダッシュボードの HTML を
返していた。

```
GET /tasks/ab920a80-...  ->  web/dist/index.html（ダッシュボード）
```

**Go の全テストと web の 109 テストが通ったまま、この状態だった。** 見つけたのは
executor が実 DB のコピーを一時 HOME で起動し、実際の URL を叩いたからである。

直し方を「`/tasks/` の 1 行を足す」にしない。**先頭セグメントを取り、
`dist/<セグメント>/_/index.html` があればそこへ振る。** ページを足しても daemon 側の
変更が要らない。

| 測ったこと | 結果 |
|---|---|
| `/tasks/<実在する ID>` | `dist/tasks/_/index.html` と一致 |
| `/goals/<実在する ID>` | `dist/goals/_/index.html` と一致（回帰なし） |
| `/nonexistent/xxx` | `dist/index.html`（従来どおり） |
| `/api/tasks/<存在しない ID>` | 404 + `task not found: ...` |

**「1 つ足すたびに 1 行足す」構造は、足し忘れたときに別のページを黙って返す。**
エラーにならないので、テストも人間も気づかない。

### 検証で一時 HOME を使うときはパスを短くする

実測: スクラッチパッド配下（100 バイト超）に一時 HOME を置くと、daemon が
`bind: invalid argument` で落ちる。macOS の unix ソケットのパス長制限（104 バイト）。
`/private/tmp/atct-vh` のような短いパスを使う。

## 変えないもの

- `DecisionAnswerForm` と `DecisionHistoryTable` は再利用する
- 回答変更（`revise`）の経路は変えない。**ページになって初めて UI から到達できる**
- i18n のキーは en / ja 両方

## 検証

- 回答履歴を持つタスクで、履歴が全件描画され**ページごと縦スクロールできる**こと
  （モーダルのように内側で切れない）
- 回答待ちの決定を持たないタスクではフォームが出ないこと（否定側）
- ゴール詳細のタスク名を押すとページに遷移すること
- **リンクが文字だけにかかること**（行全体ではない）
- 実 URL を実 DB のコピーで叩いて確かめること。**テストだけでは足りないことが
  今回わかっている**
