# 更新が来ても入力中のフォームを消さない

日付: 2026-08-20
ゴール: 更新が入ると atct の web 画面が自動リロードされてしまい、フォーム入力等が
消えてしまうので自動リロードされないようにしてほしい

## 解く問題

`subscribeToDecisionEvents` のコールバックが無条件に `load()` を呼び、画面全体を
取り直していた。**入力途中でイベントが届くと、書いていた文字が消える。**

イベントは他人の操作でも飛ぶ。**自分が書いている最中に、自分と無関係な更新で消える。**

## 決定

### 入力中は取り直さない。代わりに知らせる

**「自動リロードをやめる」だけでは足りない。** 黙って見送ると、人間は古い画面を
見ていることに気づけないまま判断する。

入力がある間は取り直しを保留し、**「新しい更新があります」を出して、人間が押したときに
取り直す。** 押すまで入力は残る。

### 入力の有無はフォームが親に伝える

フォームの中の状態を親は知らない。`onDirtyChange` / `onInputStateChange` で
フォーム側から知らせる。**親がフォームの中を覗く形にしない。**

対象は 2 つ。ゴール作成フォームと、決定の回答フォーム。

### 閉じたフォームは dirty を残さない

**アンマウント時に必ず「もう入力は無い」を送る。** これが無いと、入力したまま閉じた
フォームのせいで、ページが永久に「入力中」だと思い込み、以後の更新が全部保留になる。

```
useEffect(() => () => onDirtyChange(false), [onDirtyChange])
```

## 検証

- **入力中にイベントが来ても値が消えないこと**（否定側。これが本題）
- 入力が無いときは従来どおり自動で取り直すこと（否定側の逆）
- 保留したときに知らせが出て、押すと取り直されること
- 入力したままフォームを閉じたあと、次のイベントで取り直されること
